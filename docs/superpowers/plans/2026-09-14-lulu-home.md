# 噜噜首页实施计划

**目标：** 按 `UI_design.md` 改造整个默认首页，以墨绿夜景、薄荷绿操作区和独立水豚素材组成响应式界面。

**架构：** 沿用 React 19、TanStack Router、Base UI 和 Tailwind；公共导航增加首页专用外观，所有样式限制在 `.lulu-home` 内。保留后台配置的导航、站名、登录状态、自定义首页及项目署名。代码框为可切换和复制的示例，回复明确标为示例，不执行付费调用。

## 追加：噜噜云全站外观

用户进一步要求站点展示名统一为“噜噜云”、缩小并柔化首页文字、明显的萤火虫与漂浮装饰，以及全站墨绿底色和噜噜按钮。

- 统一站点展示配置：导航、认证页、控制台、页脚站名、浏览器标题与 favicon 使用同一品牌；旧缓存和接口站名不会覆盖展示身份。上游项目署名、版权和仓库引用保留。
- 新增默认 lulu 主题，所有路由及挂载在 body 下的表单、弹窗、下拉菜单和表格共享墨绿语义色板。主题预设使用独立 cookie，旧主题偏好保留，用户仍可主动切换其它预设。
- 登录/注册页复用夜景背景和水豚形象。首页标题最大 56px、手机 38px，导航站名 19px，标题和按钮使用圆体字体栈。
- 制作开心、眨眼、爱心和困困四款 SVG 噜噜头像；统一操作按钮、图标按钮、原生筛选按钮的轮廓、耳朵和交互状态。为紧凑分页、日期导航、密码显示和弹窗关闭按钮保留正确尺寸及定位。
- 萤火虫由 5 个增加至 18 个，移至前景，增加光晕和位移；增加 4 片飘叶、灯笼摇摆及水豚浮动。减少动态效果时全部停止。
- 补齐七种语言的主题名称。日志筛选 ModelMatchValue 收窄为 NonNullable，修复原有类型检查阻塞，筛选行为不变。

验证：25 项相关测试通过，全局 typecheck 通过，改动文件 lint 无 error（图像预加载原有 4 条事件绑定建议 warning）。已在浏览器验证桌面和手机首页、登录、注册、控制台、密钥列表/弹窗、日历、主题设置、日志筛选、模型广场及关于页；没有页面横向溢出。萤火虫和飘叶的实际 transform 随时间变化，减少动态效果下 24 个装饰元素的 animation-name 均为 none。

浏览器仍使用本地只读接口夹具。控制台验证使用虚构的预览账号和空数据，未创建账号、密钥或实际调用；验证结束后恢复访客预览。未验证生产接口和真实业务数据，未部署。

最终检查：22 个源文件格式检查通过，25 项测试通过，typecheck 和 git diff --check 通过；生产构建退出码 0（10.8 秒）。最终首页刷新后控制台无新增 error/warn，浏览器标题与导航站名均为“噜噜云”，18 个萤火虫存在且页面无横向溢出。
